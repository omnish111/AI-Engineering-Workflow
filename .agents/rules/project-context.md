# Project Context & Scope Invariants

- **Harness Isolation**: This repository (`AI Engineering Workflow`) is the software engineering factory. New user applications must be scaffolded into external directories designated by the user.
- **DNA Portability**: Software generated by this factory must include self-contained `.ai/` and entry point rules stamped via `.ai/scripts/dna-stamper.js` so it remains independent.
- **Evidence-Driven Completion**: No phase or task is marked complete without executable verification evidence recorded in task state.
