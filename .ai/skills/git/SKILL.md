# Git Skill

## When to Use

Activate this skill when the task involves:
- Git branching strategy decisions
- Commit message formatting
- Merge conflict resolution
- Repository synchronization (git-sync.js)
- Worktree management for parallel work

## Verification Expectations

- Commit messages follow conventional format
- Branches follow naming convention
- No uncommitted changes left behind
- Worktrees properly created and cleaned up
