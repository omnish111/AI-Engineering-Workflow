# Documentation Skill

## When to Use

Activate this skill when the task involves:
- Creating or updating technical documentation
- API documentation with Swagger/OpenAPI
- README or getting-started guide updates
- Architecture decision records (ADRs)
- Inline code documentation

## Verification Expectations

- All public APIs documented in Swagger
- README accurately describes current architecture
- Inline comments explain non-obvious logic
- No stale documentation references
