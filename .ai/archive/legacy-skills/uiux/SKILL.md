# UI/UX Skill

## When to Use

Activate this skill when the task involves:
- UI layout or visual design decisions
- UX flow design or user journey mapping
- Accessibility implementation (WCAG)
- Responsive design across breakpoints
- Design system or component library work

## Verification Expectations

- UI is responsive across all breakpoints
- Accessibility audit passes (WCAG 2.1 AA)
- Interactive elements have proper hover/focus states
- Loading and error states handled gracefully
- Touch targets minimum 48x48px on mobile
